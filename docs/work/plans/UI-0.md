## Goal
Every screen gets softer surfaces, matching selects and one focus style without editing any screen. UI-1…UI-4 get three shared building blocks (`Field`, `IconButton`, `Menu`) so they don't each build their own.

## Issues
F-3 (selects), the foundation for P-1 (type scale), F-2 / F-5 (field anatomy), S-2 (menu), T-4 (icon buttons). The doc 22 §5 decisions on fonts and accent are applied here. **Until you answer, the proposals in §5 are used, marked "to confirm".**

## Files I will touch
- `docs/design-system/tokens.json`:
  - radius `md` 6 → 8, `lg` 10 → 14, `xl` 16 → 18
  - lighter card border, `elevation.0` (xs shadow) for cards
  - `h1` 30 → 28 / 700, `display` 36 → 28 (page titles); Montserrat for titles only (to confirm)
  - a `focus` ring token (3 px, primary at ~35 %)
- `packages/tokens/**`: regenerated by `pnpm tokens` (never edited by hand)
- `packages/ui/src/base.css`:
  - `.select`: `appearance: none`, our own chevron (inline SVG mask using `currentColor`), same height and padding as `.input`
  - one focus ring for `.input` / `.select` / `.textarea` / `.btn`, with the border kept visible
  - `.card` uses the new border + xs shadow
  - field anatomy classes `.field__hint` and `.field__error` with an icon, and `.form-grid` (2 columns, `.wide` spans both)
- `packages/ui/src/Field.svelte` (new): props `label`, `required`, `hint`, `error`, `wide`, `id`; renders label + `*`, hint, slot, error. It passes `aria-describedby`, `aria-invalid` and `aria-required` to the control through a snippet argument.
- `packages/ui/src/IconButton.svelte` (new): an icon-only button with a required `label` (aria-label + title tooltip), sizes sm / md, variants ghost / secondary / danger.
- `packages/ui/src/Menu.svelte` (new): trigger snippet + items `{ label, icon?, href?, onclick?, danger? }`. Closes on Esc and on outside click, arrow keys move between items, focus returns to the trigger.
- `packages/ui/src/index.ts`: export the three
- `apps/web/src/screens/PageKitGallery.svelte` (**claim on the board**: unowned): one section per new piece so reviewers see them at `#/dev/page-kit`
