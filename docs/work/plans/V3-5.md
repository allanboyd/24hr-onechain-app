# V3-5 · PWA: install and update (office web + phone)

**Agent:** claude · **Branch:** `v3/V3-5-pwa` (base `design-v3`) · **Worktree:** `../btw-gd-V3-5` · **Port:** 5235
**Approved:** yes (26 Nov 2026)

## Goal
- People install the phone app from one **install page** (a QR code on a PC screen, then Android / iPhone steps).
- Installed phones show **"A new version is ready · Update"** instead of silently running old code.
- The office web app can be installed on a PC or phone.

## Files I will touch
- **Phone (`apps/field`)**
  - `src/pwa/index.ts`: detect a new service worker taking over (`controllerchange` after the first install) and raise an "update ready" flag. Expose the app version.
  - `src/pwa/UpdateBanner.svelte` (new, mounted from `src/pwa`, so `App.svelte` is untouched): "A new version is ready · Update" → reload.
  - `install.html` + `src/install/main.ts` (new second Vite entry, not in the app's entry chunk):
    - QR code of the app URL (`qrcode-generator`, MIT, no dependencies),
    - the Install button where the browser offers it,
    - iPhone steps (Share → Add to Home Screen) and Android steps.
  - `vite.config.ts`: add the `install` entry (the service worker's precache keeps only the app shell).
- **Office web (`apps/web`)**
  - `public/manifest.webmanifest` + `public/icons/**` (copied from the phone icons): name "BTW Office".
  - `sw.template.js` + the same build plugin pattern as the phone app.
    - Precached: the app shell only.
    - `/v1` (the API): never cached; the office always sees live data.
    - Navigations: network first.
    - The management report: cached on first use.
  - `index.html`: the manifest link and theme colour.
  - `src/pwa/index.ts` + `src/pwa/PwaBanner.svelte` (new): register the worker (production only), the update banner, and a one-time, dismissible "Install BTW Office" card.
  - `src/main.ts`: two lines to mount the banner (**claimed**: not owned by any other row).
- `apps/field/package.json`: the `qrcode-generator` dependency (**logged on the board**, since `pnpm-lock.yaml` is shared).
